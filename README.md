# 鼠标悬停图片自动放大预览

**网页图片悬停放大 · 高清预览 · Image Hover Zoom · 图片增强工具**

> 无需点击，鼠标移动到网页图片上即可自动显示更大的图片预览；移开鼠标后立即消失。
>
> 支持智能自适应、固定倍数放大、高清图升级、动态图片、背景图片、Lightbox / Fancybox 兼容、滚轮控制以及网站独立配置。

![效果演示](https://cdn.jsdelivr.net/gh/YDGG123/hover-image-zoom@main/ocs/images/hover-zoom.gif)


## ✨ 核心功能

- 🖱️ 鼠标悬停自动放大
- 🔍 智能自适应图片预览
- 🎯 固定倍数放大
- 🖼️ 高清图资源升级
- ⚡ 动态加载图片支持
- 🌐 部分背景图片支持
- 🎞️ Lightbox / Fancybox 兼容
- 🎚️ 滚轮缩放控制
- 🌎 按网站独立保存配置
- 🧩 Bilibili / Discuz 等场景优化
- 🛡️ 减少菜单、弹窗、播放器等页面元素误触发

## 🎯 适用场景

- 浏览论坛时快速查看缩略图
- 阅读文章时查看图片细节
- 浏览图片站时快速预览图片
- 不想频繁点击图片打开大图
- 希望不同网站使用不同的放大参数

## ⚙️ 配置

脚本提供可视化配置面板，可调整智能自适应 / 固定放大模式、放大倍数、最小图片尺寸、小图目标宽度 / 高度、最大预览尺寸以及网站独立配置。

![效果演示](https://cdn.jsdelivr.net/gh/YDGG123/hover-image-zoom@main/ocs/images/config-panel1.png)


### 🌐 网站独立配置

不同网站可以使用不同配置，例如：

```text
example.com → 智能模式
forum.example.com → 2 倍
image.example.com → 3 倍
```

## ❓ 常见问题

### 为什么有些图片不会放大？
脚本会根据图片尺寸、网页结构和当前页面状态判断是否适合预览。过小图片、控件图片以及网站特殊结构可能不会触发。

### 支持动态图片吗？
支持部分 AJAX、无限滚动、SPA 等动态加载场景。

### 会不会和网站自己的图片查看器冲突？
脚本针对 Lightbox / Fancybox 等常见查看器进行了兼容处理，并会主动避让网站自身的图片查看界面。

### 不同网站可以设置不同参数吗？
可以，网站配置会独立保存。

## 📖 项目简介

**鼠标悬停图片自动放大预览**是一款用于增强网页图片浏览体验的 Userscript。

它不仅处理普通 `<img>`，还针对动态加载、缩略图、背景图片、论坛页面以及网站自身 Lightbox / Fancybox 等复杂结构进行兼容。
