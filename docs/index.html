FAQ · 常见问题

你可能想问

为什么有些图片不放大？+
脚本会看图片尺寸、页面结构、是否被遮罩挡住。过小的图（默认低于 51px）、控件图标、以及被透明层盖住的图默认不触发——后者可以在「站点适配」里加一条容器规则解决。
会上传我的数据吗？+
不会。配置、历史记录、自定义规则都只存在本机；脚本唯一的外部请求是按站点拉取云端规则包（可关）。
会不会和网站自己的看图功能打架？+
不会。检测到 Lightbox / Fancybox 等真实灯箱时脚本主动避让；对「点一下才放大」的站点还有专门的避让开关。
不同网站能设不同参数吗？+
可以，配置按域名独立保存。这个站智能模式、那个站固定 3 倍都没问题；键位则是全局共享的。
B站 / YouTube 视频也能预览？+
能。悬停视频卡片会静音浮出播放，← → 调进度、Esc 关闭；预览期间页面不会跟着滚。
