# 悬景 · HoverVista
**鼠标悬停图片自动放大预览 · 网页图片预览 · Image Hover Zoom**

> **悬景 · HoverVista** 是产品品牌；“鼠标悬停图片自动放大预览”是功能描述。

无需点击，鼠标移动到网页图片上即可自动显示更大的图片预览；移开鼠标后立即消失。

适用于文章图片、论坛图片、缩略图、图片站等网页场景，并支持动态图片、高清图升级、部分背景图片、Lightbox / Fancybox、滚轮控制以及网站独立配置。

> 🌐 **在线介绍页（功能演示 · 配置面板实时预览 · 安装指引）**：https://ydgg123.github.io/hover-image-zoom/

## ✨ 核心功能

- 🖱️ **鼠标悬停自动放大**：移动到符合条件的图片上即可显示大图预览。
- 🔍 **智能自适应**：根据原图片尺寸和当前页面可用空间自动调整预览大小。
- 🎯 **固定倍数放大**：可以设置固定放大比例。
- 🖼️ **高清图资源升级**：7 族尺寸识别 + `srcset` / `data-*` 原图接入，反负升级闸门保证画质只升不降。
- ⚡ **动态图片支持**：兼容部分 AJAX、SPA、无限滚动等动态加载场景。
- 🌐 **背景图片支持**：CSS 背景大图同样获得完整预览（高清升级 / 滚轮 / 键位 / 历史记录）。
- 🎞️ **Lightbox / Fancybox 兼容**：网站已经打开自己的图片查看器时主动避让。
- 🎚️ **滚轮缩放**：悬停预览过程中可使用滚轮调整预览。
- 🌎 **网站独立配置**：不同网站可以保存不同的放大参数。
- 🧩 **常见网站场景优化**：针对 Bilibili、Discuz 等场景持续优化。
- 🛡️ **减少误触发**：尽量避开菜单、弹窗、播放器等页面交互元素。
- 🎛️ **全新配置面板**：8 个分区导航 + 图示化选择（放大模式 / 预览尺寸 / 出现位置 / 出现方式），改动自动保存。
- ▶️ **视频悬停预览**：悬停页面视频或 B站 / YouTube 卡片即静音浮出播放。
- 🖼️ **图集翻页与打包**：同一组图片 `←/→` 翻页，按 `z` 打包成 ZIP 下载。
- 🕘 **历史记录**：最近预览过的大图随时回看（列表 / 画廊两种视图），可删除或清空。
- ⌨️ **键位自定义**：13 个动作可视化改绑，支持一键恢复默认。
- 💾 **配置备份与恢复**：导出 / 导入 JSON，换设备或重装后一键还原。
- 🏷️ **图片信息与图说**：放大图下方显示尺寸 / 格式 / 来源，并带出图说（alt / title）。
- ⇄ **换图规则与站点适配**：三层规则（我的 / 云端 / 内置）+ 点图选图自动生成规则。
- 🇬🇧 **英文界面**：跟随浏览器 / 中文 / English，随时来回切。
- 🩺 **复制诊断信息**：一键汇总版本 / 配置 / 规则包状态，反馈更省事。

## ⚙️ 配置

脚本提供可视化配置面板（v5.9.0 起为 8 分区新版，v5.9.1 起支持中文 / English），可以调整：

- 放大模式（智能自适应 / 固定倍数）
- 预览尺寸（小 / 中 / 大 / 跟随视口，或精确设置最大宽高）
- 放大倍数、最小图片尺寸、小图目标宽度 / 高度
- 出现位置（屏幕居中 / 原图周围）与出现方式（从原图弹出 / 从原图绽开 / 直接淡入）
- 触发延迟、滚轮行为、视频预览、信息浮层、图集邻图预加载等开关
- 动作快捷键（13 项，可自定义）
- 图片规则与站点适配、历史记录
- 网站独立配置

例如：

```text
example.com       → 智能模式
forum.example.com → 2 倍
image.example.com → 3 倍
```

## 🪟 窗口切换说明

“窗口失焦时自动收起放大图”默认开启。关闭后，Alt+Tab、切换其他应用或文件管理器覆盖浏览器时，会尽量保留当前预览；切回浏览器后，如果光标仍在原图片区域，可以继续查看。

如果光标已经真正离开原图片区域，脚本仍会按正常规则立即收起。

## ❓ 常见问题

### 为什么有些图片不会放大？

脚本会根据图片尺寸、网页结构以及当前页面状态判断是否适合预览。过小图片、控件图片以及网站特殊结构可能不会触发。

### 支持动态加载图片吗？

支持部分 AJAX、无限滚动以及 SPA 页面。

### 会不会和网站自己的图片查看器冲突？

针对 Lightbox / Fancybox 等常见查看器进行了兼容处理，并会主动避让网站自身的图片查看界面。

### 不同网站可以设置不同参数吗？

可以，网站配置会独立保存。

### v5.7.2
- 修复：部分图片站（如 Unsplash）悬停无法触发放大。根因有二：① 带 background-image 的真实图片被误判为不合格而跳过；② 页面存在 aria-modal 元素时被全局误判为"已打开灯箱"，导致整页悬停预览失效。
