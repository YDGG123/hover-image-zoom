Features · 核心功能

一个脚本，照顾看图时的每个细节

从触发的时机，到预览的尺寸、加载的画质、收起的瞬间——每一步都被认真对待。

悬停自动放大

鼠标移动到符合条件的图片上，自动显示大图预览；移开立即消失。可设置悬停延迟，既灵敏又不易误触发。

智能自适应尺寸

根据原图尺寸与页面可用空间，自动算出最合适的预览大小。

固定倍数放大

设定 1.4×、2×、3×…… 预览严格按倍数呈现，小图有专属策略。

高清图资源升级

网页存在更高质量的图片资源时，预览自动换用高清版本。

动态页面支持

兼容部分 AJAX、SPA 与无限滚动页面，后加载的图片也能放大。

Lightbox 主动避让

网站打开了自己的图片查看器？HoverVista 会安静退到一边。

滚轮缩放预览

预览过程中滚动滚轮，以约 8% 步进细腻地继续放大或缩小。

网站独立配置

不同网站保存不同参数：这个站智能模式，那个站固定 3 倍。

减少误触发

尽量避开菜单、弹窗、播放器等交互元素，不打扰你的正常操作。

FAQ · 常见问题

你可能想问

为什么有些图片不会放大？+
脚本会根据图片尺寸、网页结构以及当前页面状态判断是否适合预览。过小图片（默认低于 51px）、控件图片以及网站特殊结构可能不会触发，可在配置面板中调整阈值。
支持动态加载的图片吗？+
支持部分 AJAX、无限滚动以及 SPA 页面。后加载的图片无需刷新即可悬停放大。
会不会和网站自己的图片查看器冲突？+
针对 Lightbox / Fancybox 等常见查看器做了兼容处理。当网站打开自己的图片查看界面时，HoverVista 会主动避让，不重复弹出预览。
不同网站可以使用不同设置吗？+
可以。网站配置按域名独立保存，且仅存储在浏览器本地，不会上传任何数据。
