# 悬景 · HoverVista
**鼠标悬停图片自动放大预览 · 网页图片预览 · Image Hover Zoom**

> **悬景 · HoverVista** 是产品品牌；“鼠标悬停图片自动放大预览”是功能描述。

无需点击，鼠标移动到网页图片上即可自动显示更大的图片预览；移开鼠标后立即消失。

适用于文章图片、论坛图片、缩略图、图片站等网页场景，并支持动态图片、高清图升级、部分背景图片、Lightbox / Fancybox、滚轮控制以及网站独立配置。

## ✨ 核心功能

- 🖱️ **鼠标悬停自动放大**：移动到符合条件的图片上即可显示大图预览。
- 🔍 **智能自适应**：根据原图片尺寸和当前页面可用空间自动调整预览大小。
- 🎯 **固定倍数放大**：可以设置固定放大比例。
- 🖼️ **高清图资源升级**：网页存在更高质量图片资源时，可优先使用高清版本。
- ⚡ **动态图片支持**：兼容部分 AJAX、SPA、无限滚动等动态加载场景。
- 🌐 **部分背景图片支持**：针对部分网页背景图片提供预览能力。
- 🎞️ **Lightbox / Fancybox 兼容**：网站已经打开自己的图片查看器时主动避让。
- 🎚️ **滚轮缩放**：悬停预览过程中可使用滚轮调整预览。
- 🌎 **网站独立配置**：不同网站可以保存不同的放大参数。
- 🧩 **常见网站场景优化**：针对 Bilibili、Discuz 等场景持续优化。
- 🛡️ **减少误触发**：尽量避开菜单、弹窗、播放器等页面交互元素。

## 🎯 适用场景

- 浏览论坛时快速查看缩略图
- 阅读文章时查看图片细节
- 浏览图片站时快速预览图片
- 不想频繁点击图片打开大图
- 希望鼠标移动到图片上就能看到大图
- 希望不同网站使用不同的放大参数

## ⚙️ 配置

脚本提供可视化配置面板，可以调整：

- 智能自适应 / 固定放大模式
- 放大倍数
- 最小图片尺寸
- 小图目标宽度 / 高度
- 最大预览尺寸
- 网站独立配置

例如：

```text
example.com       → 智能模式
forum.example.com → 2 倍
image.example.com → 3 倍
```

## 🪟 窗口切换说明

“窗口失焦时自动收起放大图”默认开启。关闭后，Alt+Tab、切换其他应用或文件管理器覆盖浏览器时，会尽量保留当前预览；切回浏览器后，如果光标仍在原图片区域，可以继续查看。

如果光标已经真正离开原图片区域，脚本仍会按正常规则立即收起。

## ❓ 常见问题

### 为什么有些图片不会放大？

脚本会根据图片尺寸、网页结构以及当前页面状态判断是否适合预览。过小图片、控件图片以及网站特殊结构可能不会触发。

### 支持动态加载图片吗？

支持部分 AJAX、无限滚动以及 SPA 页面。

### 会不会和网站自己的图片查看器冲突？

针对 Lightbox / Fancybox 等常见查看器进行了兼容处理，并会主动避让网站自身的图片查看界面。

### 不同网站可以设置不同参数吗？

可以，网站配置会独立保存。
